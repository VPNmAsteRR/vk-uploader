# BAS-скрипт: загрузка видео в VK Видео

Готовый проект для **Browser Automation Studio** — загружает видео в VK через
обычный браузер, без API и токенов.

```
bas/
  vk_video_upload.xml     ← открыть это в BAS (Файл → Открыть проект)
  build_bas.py            ← генератор xml (селекторы и настройки — здесь)
  check_bas.py            ← проверка синтаксиса без BAS (порт препроцессора BAS)
  simulate_bas.py         ← прогон логики на мини-рантайме (4 сценария)
  verify_selectors.py     ← проверка селекторов в настоящем Chromium
  videos.example.txt      ← пример файла со списком видео
```

---

## Как это работает

1. Читает текстовый файл со списком путей к видео (по одному на строку).
2. Для каждого файла открывает страницу загрузки VK.
3. Подставляет файл в поле выбора через перехват системного диалога
   (действие `openfile` + клик по `input[type=file]`).
4. Заполняет название и описание.
5. Нажимает «Опубликовать».
6. Ждёт результата: успех, ошибка VK или таймаут.
7. При ошибке повторяет (по умолчанию 3 попытки), затем идёт к следующему файлу.
8. Пишет отчёт `videos.txt.report.txt` рядом со списком: `OK` / `FAIL` + причина.

Важно: **один плохой файл не останавливает очередь**. Сбой изолирован блоком
«Игнорировать ошибки», счётчики и отчёт ведутся по каждому файлу.

## Запуск

1. Открой BAS → **Файл → Открыть проект** → выбери `vk_video_upload.xml`.
2. Открой скрипт и найди в самом начале блок настроек:

```js
VAR_DEMO        = false                                  // true = тест на демо-странице
VAR_VK_HOME     = "https://vk.com/feed"
VAR_UPLOAD_URL  = "https://vk.com/video?act=upload"
VAR_FILES_FILE  = "C:\vk\videos.txt"                     // ← свой список файлов
VAR_MAX_ATTEMPTS     = 3                                 // попыток на файл
VAR_UPLOAD_TIMEOUT_MS = 1200000                          // 20 минут на загрузку
VAR_WALLPOST    = false                                  // ставить «запись на стене»
```

3. Создай файл со списком видео (`C:\vk\videos.txt`), по одному пути на строку:

```
C:\vk\videos\клип 01.mp4
C:\vk\videos\клип 02.mp4
D:\видео\интервью.mov
```

Пустые строки игнорируются, `#` в начале строки — не поддерживается (не нужен).

4. Нажми **Запуск**. Первый раз:
   - откроется браузер BAS на `vk.com`;
   - если вход не выполнен, скрипт напишет в лог «Войдите в браузере» и будет
     ждать до 10 минут — войди руками (QR-код или логин/пароль), дальше он
     продолжит сам;
   - сессия сохраняется в профиле BAS, при следующих запусках вход не нужен.

Название ролика берётся из имени файла без расширения:
`клип 01.mp4` → `клип 01`.

## Проверка без аккаунта VK (демо-режим)

Скрипт можно полностью прогнать локально — на демо-странице, которая
имитирует VK и ничего не отправляет в сеть.

```bash
cd vk-uploader
../venv/bin/python vkup.py --backend demo      # поднимает http://127.0.0.1:8765
```

В BAS поставь `VAR_DEMO = true` — скрипт сам переключится на
`http://127.0.0.1:8765/mockvk/upload` и не будет требовать вход.

Список файлов укажи с реальными путями к `demo/demo1.mp4` и `demo/demo2.mp4`.
Файл с `fail` в имени демо-страница специально отклоняет — удобно проверить
повторы и отчёт.

## Если VK поменяет вёрстку

Все селекторы собраны в одном месте — словарь `SEL` в `build_bas.py`:

```python
SEL = {
    "file_input":  "//input[@type='file']",
    "title":       "(//*[@id='video_title'] | //input[@name='title'] | ...)[1]",
    "description": "(//*[@id='video_description'] | //textarea[@name='description'])[1]",
    "submit":      "(//*[@id='publish'] | //button[contains(., 'Опубликовать')] | ...)[1]",
    "login":       "(//input[@name='login'] | //*[@id='login_button'] | ...)[1]",
    "wallpost":    "(//*[@id='wallpost'] | ...)[1]",
}
```

Меняешь → пересобираешь:

```bash
python3 bas/build_bas.py
```

Альтернатива без пересборки: в BAS открой нужный блок и пересними селектор
встроенным «выбором элемента на странице» — правка сохранится прямо в проекте.

Каждый селектор — XPath, потому что одно выражение покрывает и демо-страницу
(`#video_title`), и боевую вёрстку VK (`input[name='title']`).

## Проверки, которые уже сделаны

Три уровня — можно повторить у себя:

```bash
python3 bas/check_bas.py          # синтаксис: порт препроцессора BAS + node --check
python3 bas/simulate_bas.py       # логика: 4 сценария на мини-рантайме BAS
../venv/bin/python bas/verify_selectors.py   # селекторы и JS в настоящем Chromium
```

**1. Синтаксис** (`check_bas.py`). Повторяет `Engine/preprocessor.cpp` из
открытых исходников BAS: вырезает `/*Dat:*/`-комментарии, разворачивает
`действие()!` в колбэки, затем гоняет результат через `node --check`.
Сам порт препроцессора проверен на трёх реальных проектах BAS
(`vfsauto.xml`, `AbonnementComptes.xml`, `AccountCreation.xml`) — все
разворачиваются в валидный JS.

**2. Логика** (`simulate_bas.py`). Мини-рантайм BAS на Node: `_if`, `_do`,
`foreach`, `ignore errors`, `_result`, `_break` + поддельная страница.
Проверяются 4 сценария:

| сценарий | ожидание |
|---|---|
| два нормальных файла | `OK=2, FAIL=0`, в отчёте 2 строки `OK` |
| файл, который VK отклоняет | ровно 3 попытки, `FAIL=1`, причина в отчёте |
| смешанный список (2 + 1 плохой) | `OK=2, FAIL=1`, очередь не встала |
| пустой список | понятная ошибка, скрипт не падает молча |

**3. Селекторы в браузере** (`verify_selectors.py`). Поднимает демо-сервер,
открывает Chromium и проверяет ровно те XPath и JS-сниппеты, что попали в
BAS-проект: находят ли они элементы, прикрепляется ли файл, распознаётся ли
успех и ошибка. Все проверки зелёные.

Что этими тестами **не** покрыто (и почему):

- **Вёрстка боевого VK.** Без залогиненного аккаунта страницу загрузки не
  увидеть — `vkvideo.ru/?act=upload` без сессии отдаёт заглушку. Поэтому
  селекторы для VK взяты по типовым id/name и продублированы фолбэками.
  Если VK их сменит — правится словарь `SEL` (см. выше).
- **Сам движок BAS.** Он Windows-only, здесь Linux. Поэтому вместо «поверить,
  что синтаксис верный» сделан порт препроцессора и прогон на реальных
  проектах.

## Ограничения

- **Капчу не обходит.** Если VK просит подтверждение — скрипт остановится и
  напишет в лог. Обойти нельзя и не нужно.
- **Один аккаунт.** Мультиаккаунтность не поддерживается.
- **Формат видео** должен быть тем, что принимает VK (mp4/mov/avi и т.п.);
  скрипт ничего не перекодирует.
- **Название** = имя файла. Если нужны свои названия — замени
  `VAR_TITLE = JS_BASENAME(...)` на чтение из второго столбца списка.
